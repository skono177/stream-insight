# Stream Insight - Requirements

## 1. 概要

Stream Insightは、YouTube Liveを中心としたライブ配信の公開データを収集・分析し、配信およびコメントに関する傾向を可視化する分析プラットフォームである。

## 2. 背景

ライブ配信では大量のコメントがリアルタイムに投稿されるが、配信ごとのコメント傾向やコミュニティの特徴を横断的に分析・可視化する手段は限定的である。

そこで、ライブ配信の公開データを収集し、コメント数、コメント速度、文字数、頻出ワード等の指標をBI形式で可視化するサービスを開発する。

## 3. 目的

ライブ配信におけるコメントおよび配信データを分析し、ユーザーが配信・コメントコミュニティの傾向を視覚的かつ直感的に把握できるようにする。

## 4. PoCの目的

以下の一連の処理が実現可能であることを検証する。

1. YouTube Liveの配信情報を取得できる
2. YouTube Live Chatからコメントを取得できる
3. 取得したコメントを分析できる
4. 分析結果をデータベースに保存できる
5. API経由で分析結果を取得できる
6. Web画面から分析結果を可視化できる

### 4.1. PoCで検証する主要な分析指標

- 総コメント数
- 時間帯別コメント数
- コメント速度
- 平均コメント文字数
- コメント文字数分布
- 頻出ワード
- その他、実装過程で有用性が確認できた指標

### 4.2. PoCの成功条件

特定のYouTube Live配信について、「配信 → コメント取得 → 分析 → API → Web画面」の一連の流れを実際に動作させられること。

## 5. ターゲットユーザー

- VTuber視聴者
- VTuber・配信者をリサーチするユーザー
- 配信者・VTuber
- VTuber事務所
- 配信分析API利用者

## 6. スコープ

### 6.1. 対象範囲

- YouTube Live配信情報の取得
- YouTube Live Chatコメントの取得
- コメントデータの集計・分析
- 分析結果の保存
- REST APIによる分析結果の提供
- Web UIによる分析結果の可視化
- サーバレスアーキテクチャによるAWS上での実行

### 6.2. 対象外

PoCでは以下を対象外とする。

- コメント投稿機能
- YouTube以外の配信プラットフォームへの対応
- ユーザーアカウント機能
- 課金機能
- 広告配信機能
- コメント全文の一般公開
- コメント投稿者個人のランキング
- 高度なAI分析
- 「ライバーに読まれたコメント」の高精度な自動判定
- 外部ユーザー向けAPI公開

## 7. 機能要件

### FR-001 配信情報取得

YouTube Liveの配信情報を取得できること。

### FR-002 コメント取得

対象配信のLive Chatコメントを取得できること。

### FR-003 コメント集計

取得したコメントから以下の指標を算出できること。

- コメント総数
- 時間帯別コメント数
- コメント速度
- 平均文字数
- 文字数分布
- 頻出ワード

### FR-004 データ保存

分析結果をデータベースに保存できること。

### FR-005 API提供

分析結果をREST APIとして取得できること。

### FR-006 分析結果表示

Web UIから配信を選択し、分析結果を確認できること。

## 8. 非機能要件

### NFR-001 サーバレス

可能な限りAWSのマネージドサービスおよびサーバレスサービスを利用する。

### NFR-002 コスト

PoC期間中のAWS利用料を可能な限り低く抑える。

### NFR-003 拡張性

将来的に以下へ拡張できる構成を考慮する。

- 配信者数の増加
- 配信プラットフォームの追加
- AI分析
- 外部API提供

### NFR-004 保守性

フロントエンド、API、データ収集・分析処理を
可能な限り分離する。

## 9. 将来拡張

PoC完了後、以下の機能を検討する。

- ライバー別コメント傾向分析
- 複数配信の比較
- メンバー・非メンバーの傾向分析
- Super Chat分析
- コメントコミュニティ分析
- AIによるコメント傾向分析
- ライバーに読まれたコメントの推定
- コメントが読まれやすい傾向の分析
- Twitch等への対応
- ユーザーアカウント
- お気に入りライバー
- 通知機能
- 外部API提供
- 広告による収益化
